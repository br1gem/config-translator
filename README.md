# ConfigTranslator

Консольный транслятор учебного конфигурационного языка в JSON.
Домашняя работа по конфигурационному управлению, вариант №15.

## Сборка и запуск

Для синтаксического разбора используется библиотека `swift-parsing`.
Команды выполняются из корня репозитория.

Сборка на macOS:

```bash
xcrun swift build
```

Сборка на Linux:

```bash
swift build
```

Запуск:

```bash
./run.sh --input examples/game.cfg
```

Аргумент `--input` задаёт путь к входному файлу в кодировке UTF-8.
Программа выводит JSON в стандартный вывод и возвращает код `0`.
При ошибке она пишет сообщение в стандартный поток ошибок и возвращает код `1`.

## Синтаксис

| Конструкция | Пример |
| --- | --- |
| Число с дробной частью | `12.50`, `.5` |
| Строка | `"Swift"` |
| Массив | `array(.5, "Swift")` |
| Словарь | `@{NAME = "Swift";}` |
| Имя из заглавных латинских букв | `SPEED` |
| Объявление константы | `const SPEED = 3.5` |
| Ссылка на константу | `\|SPEED\|` |

Объявления констант располагаются перед корневым значением.
Константы вычисляются по порядку объявления. В массивах и словарях
можно использовать вложенные значения и ссылки на константы.

## Примеры использования

```bash
./run.sh --input examples/game.cfg
./run.sh --input examples/weather.cfg
./run.sh --input examples/store.cfg
```

Примеры описывают настройки игры, показания метеостанции и каталог магазина.
Для `examples/game.cfg` программа выводит:

```json
{"TITLE": "Clade", "PLAYER": {"SPEED": 3.5}, "LEVELS": ["Forest", "Cave"]}
```

## Тесты

```bash
bash tests/test.sh
```

Тесты проверяют корректные конфигурации, вложенность, подстановку констант,
синтаксические ошибки, ошибки трансляции и отсутствующий входной файл.
